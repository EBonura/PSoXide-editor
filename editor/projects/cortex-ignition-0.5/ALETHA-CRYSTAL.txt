The reflection-only PSMD copy uses asset flag bit 6. Its six UV bytes contain
Q7 normal XYZ, dominant joint, then a little-endian gradient word. Bit 15 of
that word enables three 2-bit UV pairs, each mapped to (2*value - 3)*4 texels.
The loader preserves metadata instead of clamping it to the texture dimensions.
A plain geometry reimport needs the cook script to restore these values.
Runtime uses dominant-joint normals; Blender uses exact face normals.
This is a stylized reflection lookup, not real refraction or transparency.

Validation: renderer/runtime/level tests passed, including regression coverage
for gradient UV bounds and metadata preservation. The tested PS1 executable
passed hazard_scan and scratchpad stack_guard. Gameplay captures cover movement,
attacks and stance switching in the emulator; no physical-console test yet.
