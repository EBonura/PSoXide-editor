# Retired BSP and brush-world documents

These notes describe the brush/BSP world (PXBSP, the brush editor, the Quake
and Half-Life convergence work, the BSP stress calibration) that was removed
from this line when the grid world became the only world. They are kept as
history and are not maintained: paths, crate names and commands inside them
refer to code that no longer exists here. The `main` branch still has the code
they describe.
