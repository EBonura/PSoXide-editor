# Light combo v7 — compact second strike

Studio review candidate, not installed in the default project. The user accepted the look of the first and third strikes in v6 and requested substantial revision of strike two. The first and third editable masters and GLBs are byte-identical copies of v6.

The second strike now chambers the hand close to the ribs with a bent elbow, then opens the arm into a reverse cut driven alongside the existing torso turn. Upper-arm and forearm directions are authored through the active cut; the blade-facing correction is shared across the arm to preserve the stable wrist. It follows through into exactly the existing third-strike entry. The source frame 27 handoff, standalone recovery, head motion, body weight and footwork remain intact.

motion-validation.json checks compactness, blade facing during the reverse cut, unchanged non-arm channels and the exact first/third file checksums. validation.json records source contact, joint motion and the connecting pose. All masters run at 30 Hz; the opener is 61 frames and each follow-up 40 frames.

This is a visual review candidate. It has not been baked or tested in the native engine; the installed default remains v3, with its previously approved walk and opener.
